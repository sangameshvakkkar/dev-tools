# Neovim configuration

No user Neovim configuration was found when this repository was initialized.

Add your portable configuration here as `init.lua` (or `init.vim`) and any Lua modules under `lua/`. Running `..\install-config.ps1 -Tool Neovim` installs this directory to `%LOCALAPPDATA%\nvim` after backing up an existing configuration.

Do not add plugin downloads, sessions, swap files, or machine-local paths. Those are runtime state, not configuration.
